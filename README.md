# Yessine Akrout — Portfolio

Personal portfolio for video editing and motion design.

## Preview

Open `index.html` in a browser. Internet access is needed for YouTube thumbnails and web fonts. When opened directly from disk, the video dialog provides a link to watch on YouTube. Embedded playback is available when served over HTTP or HTTPS, subject to the video's embedding permissions.

## Files

- `index.html`: page content, new logo and matching favicon references.
- `style.css`: responsive styles and logo sizing.
- `app.js`: projects, filters and video player.
- `logo.png`, `favicon.png`, `photo.webp`: local brand and portrait assets.

No installation or build step is required. Edit project entries in `app.js` and page copy in `index.html`.
